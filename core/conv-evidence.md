# 근거·정량 표기 규약 (conv-evidence)

분석·검증 산출물(analyze, audit, judge, gate, test, research, model, plan)의 공통 규약.
모든 팩에 설치되며, 이 규약은 각 스킬의 개별 지시보다 우선한다.

## 원칙: 추측 금지

- 공개된 데이터 또는 직접 확인으로 뒷받침되지 않는 내용은 단언하지 않는다.
- 근거가 없으면 지어내지 않고 '미확인'으로 표기하거나 사용자에게 질문한다.
- 유사한 사례·이름을 근거로 다른 대상을 같은 것으로 취급하지 않는다.

## 확신도 3분류 (모든 주장·수치에 부여)

- **확정** — 공개 데이터·직접 확인 출처 1개 이상. 단언 가능.
- **추정** — 근거는 있으나 1차 출처가 아니거나 불완전. 산출식·유추 과정을 명시한다.
- **미확인** — 근거 없음. 본문에서 이 표식과 함께만 노출한다.

## 정량 표기 구조 (필수)

수치는 아래 4요소를 갖춰 적는다. 출처 없는 수치를 확정처럼 쓰지 않는다.

| 요소 | 예 |
|------|-----|
| 값 + 단위 | 1,200억 원 |
| 기준 시점 | 2025년 기준 |
| 출처 (공개 데이터) | 통계청 KOSIS, 접근일 2026-07-13 |
| 확신도 | 확정 / 추정(산출식 명시) / 미확인 |

인라인 표기 예:

- 확정: `국내 시장 규모 1,200억 원 (2025 기준, 출처: 통계청 KOSIS 접근 2026-07-13, 확정)`
- 추정: `CAC 12,000원 (추정 — 업계 평균 CPC 400원 × 전환율 3% 역산, 출처: 네이버 광고 공시 단가)`
- 미확인: `경쟁사 A 유료 전환율 [미확인 — 공개 데이터 없음, 인터뷰 필요]`

## 검증 보고 3종 구분

분석·검증 결과는 세 종류를 **분리해** 보고한다. 셋을 섞지 않는다.

- **긍정 (strength)** — 잘 되어 있는 것. 근거와 함께.
- **부정 (finding)** — 문제. 심각도·근거·수정 제안과 함께.
- **공백 (gap)** — 부족한 것·채워야 할 것. 판단 근거가 없어 확인이 필요한 항목 포함.

특히 '공백'을 '부정'으로 둔갑시키거나 조용히 생략하지 않는다 —
근거가 없어서 판단하지 못한 항목은 그 자체로 도출되어야 할 결과물이다.
