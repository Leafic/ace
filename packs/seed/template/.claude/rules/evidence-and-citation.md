# 근거·인용 규약 (v0.1)

이 씨앗이 처음부터 강제하는 유일한 품질 규약.
이유: LLM 지식노동 최대 실패모드는 환각/근거없음이고 첫 메시지부터 발생 → day-zero 필요.

## 확증과 추론의 분리
- 확증 = 직접 Read/조회/관찰한 출처가 있는 주장. 단언 가능.
- 추론 = 근거에서 유추한 것. 반드시 '추정'으로 표기.
- 라벨·이름 유사로 다른 출처를 같은 것으로 취급 금지.

## 확신도 3분류 (brief.md 각 논점에 부여)
- 확정 — 출처 1개 이상 + 직접 확인
- 추정 — 근거는 있으나 1차 출처 아니거나 불완전
- 미확인 — 근거 없음. 본문에서 이 표식과 함께 노출.

## 출처 표기
- 외부 사실·수치는 출처 인접 표기(링크/파일/인터뷰 + 접근일), 가능하면 축자 인용.

## 자가 점검 (산출물 확정 전)
- [ ] 모든 '확정' 논점에 출처 1개 이상
- [ ] '추정/미확인'이 '확정'과 분리 표기됨
- [ ] 직접 확인 안 한 것을 확증처럼 단언 안 함
