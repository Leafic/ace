# 자라는 방법 — 씨앗의 진화 엔진 (v0.1)

빈 v0.x에서 회고로 자란다. 완성형으로 채우지 마라. 아래 루프로 키워라.

## 원칙: 방어는 사고 뒤에 짓는다
- 게이트·훅·서브에이전트·스킬을 미리 만들지 않는다. 마찰 생기기 전엔 비워 둔다.
- 판별: "실제 겪은 실패를 막나, 겪을까봐 짐작으로 짓나?" 후자면 짓지 않는다.

## 루프
1. 감지 — 잘못된 단정·재작업·놓친 근거를 알아챈다.
2. 기록 — workspace/improvements/에 1건 1파일로 사실만.
3. 승격 — 같은 유형이 2회 이상 반복되면: 매번 의식할 일→rules / 자꾸 어기는 무결성→hooks /
반복 절차→skills / 반복 산출물조각→library.
4. 최소로 — 한 번에 하나. 부정문보다 "이렇게 하라"로.

> 무엇을·어떻게 심을지 막히면 → BLUEPRINT.md를 읽어라(검증된 구조결정 9개의 왜/신호/법).
> 단 청사진은 참고일 뿐 — 여전히 실제 신호가 온 것만 심는다.
